{{ if $zh }}关于 PGSTY{{ else }}About PGSTY{{ end }}

{{ if $zh }}我们的使命，是帮助这个世界用好 PostgreSQL。{{ else }}Our mission is to help the world make the most of PostgreSQL.{{ end }}

{{ if $zh }}

{{ $m.since_year }} 年，这一切从一位 DBA 的私人工具箱开始 —— 一堆把 PostgreSQL 跑好的脚本。{{ $m.oss_since_year }} 年它开源，长成了发行版 Pigsty，随后长出包管理器、指标导出器，以及整个生态共用的软件仓库与扩展目录。

半路上还多了第二面旗帜：Silo —— PIGSTY 维护的 MinIO 分支。S3 兼容对象存储，持续安全更新，管理控制台与完整发行制品都还在线，如今已有 {{ partial "compact-number.html" $silo.stars }} 星标。维护好一个被上游放下的项目，和写出一个新项目一样，是对生态实打实的贡献。工具箱变成了生态，作者身后有了一家公司：PGSTY。

{{ else }}

In {{ $m.since_year }} this was one DBA's private toolbox — a pile of scripts for running PostgreSQL properly. It went open source in {{ $m.oss_since_year }}, grew into the Pigsty distribution, then a package manager, a metrics exporter, and the public repositories and extension catalog the wider ecosystem runs on.

Along the way we raised a second flag: Silo, the PIGSTY-maintained fork of MinIO — S3-compatible object storage with ongoing security updates, a working console, and full release artifacts still shipping, now at {{ partial "compact-number.html" $silo.stars }} stars. Keeping alive a project its upstream set down is as real a contribution as writing a new one. The toolbox became an ecosystem, and behind its author now stands a company: PGSTY.

{{ if $zh }}THE MISSING i · 少掉的 i{{ else }}THE MISSING i{{ end }}

{{ if $zh }}少掉的那个 i{{ else }}The story of the missing i{{ end }}

{{ if $zh }}

Pigsty 这个名字本来是句缩写：PostgreSQL In Great STYle —— 六个字母，PIGSTY。轮到给公司注册名字时，我们却只写了五个：PGSTY。不是笔误，是故意少了一个。

少掉的 i 是 Infrastructure（基础设施）：repo.pigsty.io 全球软件仓库与 repo.pigsty.cc 大陆镜像、精确到操作系统小版本的离线安装包，还有 pgext.cloud 扩展目录 —— 收录 {{ lang.FormatNumber 0 $m.ext_catalogued }} 个扩展，{{ $m.ext_packaged }} 个打包即装。这些东西不用注册账号、不用授权码，也不用先聊一单生意。

我们把这一层当整个生态的公共设施来运营，而不只是自家用户的福利 —— 因为生态的可持续，本身就是一种基础设施。数据库比厂商活得久，靠软件包吃饭的社区，值得一个不断供的仓库。

所以公司名字讲的就是这么一件事：产品留着六个字母，公司用五个干活。那个 i 是我们送出去的 —— 向所有人免费，永远免费。

{{ else }}

Pigsty started as an acronym: PostgreSQL In Great STYle — six letters, PIGSTY. When the time came to register a company, we wrote down five: PGSTY. Not a typo. We took one letter out on purpose.

The missing i is Infrastructure: the global package repository at repo.pigsty.io and its mainland-China mirror repo.pigsty.cc, offline packages pinned to exact OS minor versions, and the extension catalog at pgext.cloud — {{ lang.FormatNumber 0 $m.ext_catalogued }} extensions catalogued, {{ $m.ext_packaged }} packaged and ready to install. None of it asks for an account, a license key, or a sales call.

We run this layer as a public utility for the whole ecosystem, not as a perk for our customers — because ecosystem continuity is itself infrastructure. Databases outlive vendors, and a community that lives on packages deserves repositories that stay up.

So that is the story the name tells: the product keeps its six letters, the company works with five. The i is the letter we gave away — free for everyone, forever.

{{ end }}
