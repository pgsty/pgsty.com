{{ if $zh }}SOLUTIONS · 方案{{ else }}SOLUTIONS{{ end }} · CLOUD EXIT

{{ if $zh }}下云，把数据库拿回来{{ else }}Stop renting your database{{ end }}

{{ if $zh }}下云不是情怀，是一笔算得清的账 —— 这里有账本，也有路线图。{{ else }}Cloud exit isn't sentiment — it's a balance-sheet decision. Here's the ledger, and the road.{{ end }}

{{ if $zh }}

云数据库当年解决的是真问题：把 PostgreSQL 跑好，过去确实需要一位专家。租一个省心的 RDS，在那个年代是理性的选择。但这些年，高可用、备份恢复、监控告警这些「DBA 的手艺」被一样样做进了开源软件 —— 你付的租金，买的越来越多是十年前的稀缺性。

与此同时，两条价格曲线岔开了：NVMe 存储和整机服务器一年比一年便宜，云上 RDS 的标价却没怎么跟着降。你留在云上的每一年，租与买的差距都在扩大 —— 完整的论证在我们的下云专栏里。

拥有不等于单干。Pigsty 把企业级 PostgreSQL 的整套能力做成了开源软件，作者本人的订阅与专家服务在后面兜底 —— 下面是账，和路。

{{ else }}

Managed databases solved a real problem: running PostgreSQL well used to take a specialist, and renting one from the cloud was the rational call. But year by year, the DBA's craft — HA, backup and recovery, monitoring — has been built into open-source software. More and more, the rent buys you scarcity that no longer exists.

Meanwhile the price curves have split: NVMe storage and commodity servers get cheaper every year, while RDS list prices barely move. Every year you stay, the gap between renting and owning compounds — the long-form case lives in our cloud-exit essays.

Owning doesn't mean going it alone. Pigsty packages the whole enterprise-PostgreSQL stack as open source, with the author's subscriptions and expert services behind it. Below: the ledger, then the road.

{{ end }}

{{ if $zh }}「高可用我们做不过云厂商。」{{ else }}"We can't do HA as well as the cloud."{{ end }}

{{ if $zh }}你不用自己做：Patroni + etcd 自愈故障切换、pgBackRest 时间点恢复，默认配置就是生产级。demo.pigsty.io 上跑着一套公开的真实集群，随时去看。{{ else }}You don't have to build it: self-healing failover on Patroni + etcd and point-in-time recovery with pgBackRest ship as defaults.
