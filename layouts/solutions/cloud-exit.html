{{ if $zh }}SOLUTIONS · 方案{{ else }}SOLUTIONS{{ end }} · CLOUD EXIT

{{ if $zh }}下云，把数据库拿回来{{ else }}Stop renting your database{{ end }}

{{ if $zh }}下云不是情怀，是一笔算得清的账。这一页就是账本：单价、案例、路线图，每个数字都有出处。{{ else }}Cloud exit isn't sentiment — it's arithmetic. This page is the ledger: unit prices, receipts, and the road out, every figure with a source.{{ end }}

{{ if $zh }}

云数据库当年解决的是真问题：把 PostgreSQL 跑好，过去确实需要一位专家，租个省心的 RDS 是理性选择。但这些年，高可用、备份恢复、监控告警这些「DBA 的手艺」被一样样做进了开源软件 —— 你付的租金，买的越来越多是十年前的稀缺性。

与此同时，两条价格曲线彻底岔开了。同样一核算力跑一个月：自建物理机大约 ¥{{ $sp.idc }}，租阿里云的高可用 RDS 要 ¥{{ $sp.rds2 }}–{{ $sp.rds8 }}，租 AWS 的要 ¥{{ $sp.awss4 }}–{{ lang.FormatNumber 0 $sp.awsha8 }}[1]。计算与存储硬件一年比一年便宜，云数据库的挂牌价却纹丝不动 —— 你留在云上的每一年，租与买的差距都在复利。

拥有不等于单干。Pigsty 把企业级 PostgreSQL 的整套能力做成了开源软件，作者本人的订阅与专家服务在后面兜底。下面是账，然后是路。

{{ else }}

Managed databases solved a real problem: running PostgreSQL well used to take a specialist, and renting one was the rational call. But year by year the DBA's craft — HA, backup and recovery, monitoring — has been built into open-source software. More and more, the rent buys scarcity that no longer exists.

Meanwhile the price curves have split for good. One vCPU running for one month: about ¥{{ $sp.idc }} on a self-hosted dedicated server, ¥{{ $sp.rds2 }}–{{ $sp.rds8 }} on Aliyun's HA RDS, ¥{{ $sp.awss4 }}–{{ lang.FormatNumber 0 $sp.awsha8 }} on AWS[1]. Hardware gets cheaper every year; RDS list prices barely move. Every year you stay, the gap between renting and owning compounds.

Owning doesn't mean going it alone. Pigsty packages the whole enterprise-PostgreSQL stack as open source, with the author's subscriptions and expert services behind it. Below: the ledger, then the road.

{{ if $zh }}OBJECTIONS · 反对意见{{ else }}OBJECTIONS{{ end }}

{{ if $zh }}你会被问到的三句话{{ else }}The three pushbacks you'll hear{{ end }}

{{ if $zh }}「自建运维负担太重。」{{ else }}"Self-hosting is an ops burden."{{ end }}

{{ if $zh }}手搓高可用、备份、监控的年代确实如此。Pigsty 把这些做成了软件 —— 让初级工程师拥有专业 DBA 70% 以上的能力；最难的那一截，由写代码的人提供服务兜底。探探两三个人的 DBA 团队管着两万五千核，就是这套逻辑的实证。{{ else }}It was, when HA, backups, and monitoring were hand-built. Pigsty ships them as software — it gives a junior engineer 70%+ of a professional DBA's capability — and the author's expert services stand behind the hardest stretch. Tantan's two-to-three-person DBA team running 25,000 cores is this logic, proven.{{ end }}

{{ if $zh }}「高可用我们做不过云厂商。」{{ else }}"We can't do HA as well as the cloud."{{ end }}

{{ if $zh }}你不用自己做：Patroni + etcd 自愈故障切换、pgBackRest 时间点恢复，默认配置就是生产级。demo.pigsty.io 上跑着一套公开的真实集群，随时去看。{{ else }}You don't have to build it: self-healing failover on Patroni + etcd and point-in-time recovery with pgBackRest ship as defaults. A real cluster runs in the open at demo.pigsty.io — go look.{{ end }}
