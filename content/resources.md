PGSTY maintains public resources that help people install, understand, and use PostgreSQL. These resources are available whether or not you purchase professional services.

- **[PGSTY Repository](https://pigsty.io/docs/repo/)** — PostgreSQL, extensions, and infrastructure packages for Linux, with APT and YUM repositories and installation guides.
- **[PostgreSQL in Chinese](https://pgsql.cc/docs/)** — Chinese translations of PostgreSQL manuals, maintained across versions, with search and ecosystem documentation.
- **[PG.CENTER](https://pg.center/)** — English PostgreSQL manuals, version comparisons, technical reference, and ecosystem information.
- **[PostgreSQL Knowledge Graph](https://pg.center/wiki/)** — Connected references for SQL, parameters, functions, and system catalogs, with version context and links to sources.
- **[PGEXT.CLOUD](https://pgext.cloud/)** — An extension catalog covering purpose, version compatibility, and package availability.
