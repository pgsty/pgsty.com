## Software you can inspect and evaluate

PGSTY develops and maintains an end-to-end open-source data infrastructure stack centered around PostgreSQL. Our ecosystem spans database distributions, S3-compatible object storage, package managers, monitoring exporters, specialized extensions, repository publishing, and local development environments. Each project is published with public source code and documentation.

Start with the relevant project documentation for installation requirements, supported platforms, and releases. For a production deployment, [our professional services](/services/) can help with assessment, implementation, and operational handover.

## Project licences and commercial support

These projects use standard open-source licences: Pigsty, PIG, pg_exporter, SOW, Barn, Oink, and our extensions use Apache-2.0; Silo uses AGPL-3.0. Third-party components and dependencies retain their own licences. Refer to the licence files in each repository for the applicable terms.

Public documentation, releases, and community discussions are available through the project links. Commercial support is a separate engagement with an agreed scope; availability of open-source software does not create a support or service-level commitment.
